HOW IT WORKS

المبدأ ببساطة

البوت مش كلود لحالو. هو صفحة شات صغيرة، ووراها سيرفر، والسيرفر هو الي بيحكي مع كلود. كل سؤال بيمرق بأربع محطات:

  1. الزبون بيسألمن أي موبايل أو لابتوب، عالرابط تبع البوت
  2. السيرفر بيستلم السؤالشغّال على Vercel، ومفتاح الـAPI مخبّى عندو، ما بيوصل للزبون أبدا
  3. بيبعتو لكلود مع ملفاتكومعو قاعدة واضحة: جاوب من هالملفات بس
  4. والرد بيرجع للزبونمن ملفاتك إنت، مش من راس كلود

يعني البوت ما "بيتعلم" متل ما الناس متخيلة. بكل سؤال، السيرفر بيعطي كلود ملفاتك من جديد، وكلود بيجاوب منها. ولهيك أي تعديل بتعملو على الملفات، البوت بيعرفو فورا

  • ✓ يجاوب من الملفات بس
  • ✓ إذا ما لقى الجواب، يقول ما عندو هالمعلومة ويعطي طريقة التواصل

THE STEPS

الخطوات بالتفصيل

01

خود نسخة من الريبو

  1. اعمل حساب على github.com إذا ما عندك
  2. افتح الريبو واكبس Fork فوق، وبعدين Create fork
  3. هيك صار عندك نسخة كاملة بحسابك: your-name/ai.byrawan، والبوت بفولدر 01-files-chatbot
02

اعمل مفتاح API

  1. افتح console.anthropic.com وسجّل
  2. من Billing زيد رصيد صغير، 5$ بيكفوا للتجربة وأكتر
  3. من Limits حط حد صرف بالشهر، متل 5$. هيك حتى لو حدا ضغط عالبوت، ما رح يصرف أكتر
  4. من API Keys اكبس Create Key، سمّيه متل my-bot، وانسخو بزر النسخ. المفتاح بيبلش بـsk-ant-
المفتاح متل كلمة السرلا تبعتو لحدا، ولا تحطو بأي ملف بالريبو، ولا تصوّرو. مكانو الوحيد هو إعدادات Vercel بالخطوة الجاية
03

انشرو على Vercel

  1. افتح vercel.com وفوت بـContinue with GitHub
  2. افتح vercel.com/new. تحت Import Git Repository اكبس Import جنب ai.byrawan. إذا مش ظاهر، اكبس Adjust GitHub App Permissions وعطيه وصول للريبو
  3. Project Name: اسم قصير، لأنو رح يصير هو الرابط. مثلا my-bot بيعطيك my-bot.vercel.app
  4. Root Directory: اكبس Edit، اختار 01-files-chatbot، وContinue
  5. Application Preset: خليه Other. إذا طلع تحذير Possible configuration mismatch، عادي، تجاهلو
  6. افتح Environment Variables: بالـKey اكتب ANTHROPIC_API_KEY، وبالـValue الصق المفتاح بدون أي فراغ
  7. اكبس Deploy. بعد ثواني بيطلعلك Deployed to Production، واكبس Visit لتشوف البوت شغال بمثال مستر بن
04

بدّل الملفات بملفاتك

هون البوت بيصير إلك. أول شي خلّي كلود يكتبلك الملفات:

  1. افتح كلود، وارفعلو المنيو أو معلومات مشروعك: صورة، PDF، أو نص منسوخ
  2. اطلب منو هيك:
PROMPT · انسخوحوّلي هالمعلومات لملفين لبوت بيجاوب الزباين. الأول اسمو menu.md فيه المنتجات أو الخدمات مع الأسعار، كل قسم بعنوان، وكل منتج بسطر فيه الاسم والسعر بالعملة. التاني اسمو info.md فيه أوقات الدوام والمكان والحجز والتوصيل والدفع والسياسات. اسألني عن أي معلومة ناقصة قبل ما تكتبهم، وما تخترع شي مش موجود

كلود رح يسألك عن الناقص، وبعدين بيعطيك الملفين. وبعدها بنسختك على GitHub:

  1. افتح 01-files-chatbot/knowledge
  2. افتح menu.md، اكبس ✏️، امسح المحتوى، الصق ملفك، واكبس Commit changes. ونفس الشي لـinfo.md
  3. افتح config.json، اكبس ✏️، وبدّل الاسم والترحيب والأسئلة الجاهزة وطريقة التواصل واللون، وCommit changes
  4. إذا عندك لوقو: من فولدر public اكبس Add file ← Upload files، ارفع صورة مربعة، وحط اسمها بخانة logo

Vercel بيلاحظ التعديل لحالو، وبعد دقيقة بيصير البوت بملفاتك على نفس الرابط

05

جرّبو قبل ما تنشر الرابط

اسألو تلات أنواع أسئلة:

  • سؤال جوابو بملفاتك: لازم يجاوب صح، والسعر متل ما هو بالملف
  • سؤال مش بملفاتك: لازم يقول ما عندو هالمعلومة ويعطي طريقة التواصل، بدون ما يألّف
  • سؤال برا الموضوع: متل "اكتبلي قصيدة"، لازم يعتذر بلطف

وبعدين حط الرابط ببايو إنستقرام، أو بالواتساب بزنس، أو اطلب من كلود يعملك QR code للرابط وحطو عالطاولات أو بالمحل

COST & SAFETY

الكلفة والأمان

  • الموديل: البوت شغّال على Claude Haiku 5.5، أسرع وأرخص موديل عند كلود. كل رسالة بتكلف بحدود جزء من السنت، يعني رصيد 5$ بيكفي آلاف الرسائل. الكلفة بتزيد إذا كبرت ملفاتك كتير
  • حد الصرف: الحماية الأساسية هي الحد الشهري الي حطيتو بالـConsole
  • حد الرسائل: كل زائر إلو 20 رسالة كل 10 دقايق، لحتى ما حدا يستغل البوت
  • المفتاح: بيضل بالسيرفر، والزبون ما بيشوفو أبدا
  • Vercel: الخطة المجانية Hobby للمشاريع الشخصية. إذا البوت لمشروع تجاري كبير، شوف شروط Vercel

الأسعار بتتغير، فشوف آخر أسعار بصفحة Anthropic قبل ما تبلش

IF YOU GET STUCK

إذا علقت

البوت بيكتب «صار في مشكلة بالرد»

يعني البوت وصل لكلود بس Anthropic رجّعت خطأ. افتح مشروعك على Vercel ← Logs، ابعت سؤال للبوت، وشوف السطر الأحمر الي فيه Anthropic API error:

  • 401 invalid x-api-key: المفتاح انلصق غلط. اعمل مفتاح جديد، بدّلو من Settings ← Environment Variables، وبعدين Deployments ← آخر نشر ← ⋯ ← Redeploy
  • خطأ عن الرصيد أو credit: الرصيد خلص أو مش بنفس الـworkspace الي فيه المفتاح. شيك Billing بالـConsole
البوت بيكتب «ANTHROPIC_API_KEY ناقص»

المفتاح مش محطوط بـVercel، أو انحط بعد النشر. زيدو من Settings ← Environment Variables واعمل Redeploy. أي تعديل بالمتغيرات ما بيوصل للبوت بدون نشر جديد

عدّلت الملفات والبوت لسا بيجاوب القديم

استنى دقيقة وحدّث الصفحة. إذا ضل، افتح Deployments على Vercel وشوف إذا آخر نشر خلص أو في خطأ. وتأكد أنك عدّلت بنسختك إنت، مش بالريبو الأصلي

البوت عم يجاوب شي مش موجود بملفاتي

جرّب نفس السؤال كم مرة. إذا ضل يألّف، زيد المعلومة الصح بالملف، أو زيد بالملف سطر واضح متل «ما في عنا توصيل خاص». وكل ما كانت ملفاتك أوضح، كل ما كان البوت أدق

Vercel طلّع تحذير Possible configuration mismatch

عادي، لأنو Vercel شاف ملف package.json وتوقع framework. البوت ما بدو build، فخليه Other وكمّل
