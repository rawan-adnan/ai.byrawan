# شات بوت بيجاوب زباينك من ملفاتك

**BUILD IT WITH CLAUDE · ابني بكلود · الحلقة 01**

موقع صغير فيه شات بوت، بيجاوب الزباين عن المنيو والأسعار وأوقات الدوام والشروط، **من ملفاتك إنت بس**. إذا السؤال مو موجود بملفاتك، ما بيألّف جواب، بيقول للزبون كيف يتواصل معك.

المثال الموجود هون لمحل قهوة وهمي اسمو "كافيه بيس". بتبدّل ملفاتو بملفاتك وبيصير البوت إلك.

## 👈 جرّبو هلأ

**[افتح البوت وجرّب](https://rawan-bot.vercel.app)**

اسألو عن المنيو، الأسعار، أوقات الدوام، أو اسألو عن شي مش موجود (متل "عندكن بيتزا؟") وشوف كيف بيتصرف.

---

## بدك ياه لمحلك أو مشروعك؟

الفكرة كلها بفولدر واحد اسمو `knowledge`: فيه ملفات نصية عن المحل. البوت ما بيعرف شي غير الي مكتوب فيها. يعني لتصير النسخة إلك، بتعمل 3 شغلات:

1. **بتنشر نسختك** بكبسة زر (الخطوة 2 تحت).
2. **بتخلي كلود يكتبلك ملفاتك** من المنيو أو الأسعار أو أي معلومات عندك (الخطوة 3).
3. **بتحط ملفاتك مكان ملفات المثال** وبتغيّر الاسم واللون (الخطوة 4).

ما بتحتاج تعرف برمجة، وما في ولا سطر كود لازم تلمسو.

---

## شو بتحتاج

- حساب GitHub (ببلاش)
- حساب Vercel (ببلاش، بتفوت عليه بحساب GitHub)
- مفتاح API من Anthropic، يعني الشي الي بيخلي البوت يحكي مع كلود. الدفع حسب الاستخدام، وفيك تحط حد أعلى للصرف بالشهر.

---

## الخطوات

### 1. جيب مفتاح الـAPI

1. افتح [console.anthropic.com](https://console.anthropic.com) وسجّل.
2. من **Billing** زيد رصيد صغير، ومن **Limits** حط حد للصرف بالشهر.
3. من **API Keys** اعمل مفتاح جديد وانسخو. **لا تبعتو لحدا ولا تحطو بأي ملف.**

### 2. انشر البوت بكبسة وحدة

اضغط هالزر:

<div dir="ltr">

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Frawan-adnan%2Fai.byrawan%2Ftree%2Fmain%2F01-files-chatbot&env=ANTHROPIC_API_KEY&envDescription=%D9%85%D9%81%D8%AA%D8%A7%D8%AD%20API%20%D9%85%D9%86%20console.anthropic.com&project-name=my-chatbot&repository-name=my-chatbot)

</div>

- Vercel رح يعمل نسخة من البوت بحسابك على GitHub.
- رح يطلب منك `ANTHROPIC_API_KEY`: الصق المفتاح الي نسخته.
- اضغط **Deploy**، وبعد دقيقة بيعطيك رابط البوت شغال، بمثال كافيه بيس.

### 3. خلّي كلود يحوّل معلوماتك لملفات

البوت بيقرا ملفات نصية بفولدر `knowledge`. ما لازم تكتبها بإيدك، كلود بيعملها:

1. افتح كلود، وارفعلو المنيو تبعك (صورة، PDF، أو حتى نص منسوخ).
2. اطلب منو:

> حوّلي هالمنيو لملف اسمو menu.md، كل قسم بعنوان، وكل صنف بسطر فيه الاسم والسعر بالعملة. وبعدين اعملي ملف info.md فيه أوقات الدوام والمكان والحجز والتوصيل والدفع والسياسات، واسألني عن أي شي ناقص.

3. كلود رح يسألك عن المعلومات الناقصة ويطلّعلك الملفين.

### 4. حط ملفاتك مكان المثال

بنسختك على GitHub (الي عملها Vercel):

1. افتح فولدر `knowledge`، واحذف `menu.md` و`info.md` القدام، وارفع ملفاتك (**Add file** ← **Upload files**).
2. افتح `config.json` واضغط ✏️، وبدّل: اسم المحل، اسم البوت، رسالة الترحيب، الأسئلة المقترحة، طريقة التواصل، واللون.
   - **اللوقو:** ارفع صورة اللوقو تبعك لفولدر `public` (مربعة، PNG أو SVG)، وحط اسمها بخانة `logo`. إذا شلت الخانة، بيطلع أول حرف من اسم المحل.
3. اضغط **Commit changes**.

Vercel بيحدّث البوت لحالو خلال دقيقة. ما في شي تاني تعملو.

### 5. شارك البوت

- حط الرابط ببايو إنستقرام أو بالواتساب بزنس.
- أو اطلب من كلود يعملك QR code للرابط، وحطو عالطاولات.

## أسئلة بتتكرر

**البوت ممكن يألّف أسعار؟**
البوت معطى تعليمات صارمة يجاوب من ملفاتك بس، وإذا ما لقي الجواب بيحوّل الزبون لطريقة التواصل الي حطيتها. بس متل أي AI، جرّبو بأسئلتك قبل ما تنشرو، وخلّي ملفاتك واضحة ومحدثة.

**قديش بيكلف؟**
البوت شغال على موديل Haiku، وهو أرخص موديل عند كلود وأسرعها. والملفات بتنحفظ مؤقتا بين الأسئلة (prompt caching) فبتنقص الكلفة. الأهم: حط حد للصرف بالخطوة 1.

**بدي غيّر شي بشكل البوت أو طريقة ردو؟**
افتح نسختك من الريبو بكلود (عن طريق ربط GitHub)، واطلب التعديل بكلامك. مثلا: "خلّي البوت يرد بالإنجليزي إذا الزبون كتب إنجليزي، وزيدلي لوجو المحل فوق".

**بدي جربو على جهازي قبل؟**

<div dir="ltr">

```bash
ANTHROPIC_API_KEY=your-key node server.js
# افتح http://localhost:3000
```

## شو في جوا الفولدر

<div dir="ltr">

```
knowledge/      ← ملفاتك (md أو txt). البوت بيقرا كل شي هون
config.json     ← الاسم، الترحيب، الأسئلة المقترحة، التواصل، اللون، اللوقو
public/         ← صفحة الشات واللوقو (logo.svg)
api/chat.js     ← بيبعت السؤال مع ملفاتك لكلود. المفتاح بيضل هون، ما بيوصل للزبون
api/config.js   ← بيعطي الصفحة الاسم واللون
server.js       ← للتجربة على جهازك بس
```
